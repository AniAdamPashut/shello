# shello Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Go CLI, `shello`, that sends the last N terminal commands (with their output and exit codes) plus the user's question to an AI agent CLI (default `claude`). Shell hooks record that history, and `install.sh` installs everything.

**Architecture:**
- **Recording:** an rc snippet re-runs the interactive shell inside util-linux `script`, which logs the terminal stream to a file.
- **Markers:** per-shell hooks print invisible OSC markers around each command and append the command's text and exit code to a JSONL side file.
- **The binary:** reads both files, slices out each command's output, cleans and truncates it, fills a prompt template, and either `exec`s the agent's interactive command or pipes the prompt into its print command.

**Tech Stack:** Go (stdlib + `github.com/BurntSushi/toml`), POSIX sh, bash/zsh/fish, util-linux `script`.

**Spec:** `docs/superpowers/specs/2026-10-20-shello-design.md`

## Global Constraints

- Linux only; util-linux `script` invoked as `script -q -f -O <log> -c <cmd>`.
- Single static binary: build with `CGO_ENABLED=0`. Only non-stdlib dependency: `github.com/BurntSushi/toml`.
- State dir: `${XDG_STATE_HOME:-$HOME/.local/state}/shello/sessions/` (mode 0700). Files `<id>.log`, `<id>.cmds`, `<id>.started` (mode 0600). Delete files older than 7 days at session start.
- Config dir: `${XDG_CONFIG_HOME:-$HOME/.config}/shello/` holding `config.toml` and `prompt.md`. If either file is missing, use the embedded defaults.
- Environment variables:
  - `SHELLO_SESSION`: session id.
  - `SHELLO_TTY`: tty device path.
  - `SHELLO_DIR`: sessions dir.
  - `SHELLO_DISABLE=1`: skip everything.
- Markers (exact bytes):
  - start: `\x1b]6973;start;<seq>\x07`
  - end: `\x1b]6973;end;<seq>;<exit>\x07`
  - `<seq>` is `<shell pid>.<counter>`, matching `[0-9]+\.[0-9]+`. The pid prefix stops subshells on the same TTY from colliding.
- `.cmds` line: `{"seq":"<seq>","cmd":"<text>","exit":<int>,"ts":<unix seconds>}`.
- Defaults:
  - `commands = 3`, `head_lines = 100`, `tail_lines = 100`
  - `max_log_bytes = 2097152`
  - interactive prompt limit: 120000 bytes
- No-question text: `Explain what happened in these commands and whether anything went wrong.`
- Never-recording message: `shello isn't recording this terminal — run install.sh and open a new terminal`

## Review Focus

1. **PTY output uses `\r\n` line endings.** Cleaning must treat `\r\n` as a newline and not as a carriage-return overwrite, or every line gets erased. Tested in Task 2.
2. **Command text with quotes, backslashes, tabs, newlines or unicode** must round-trip through the shell's JSON escaping to the exact original. Tested in Task 6.
3. **The log tail starts in the middle of a command,** so its start marker is gone. Show `[output not available]`, not the wrong output. Tested in Task 3.
4. **A session with fewer than N commands, or zero.** Use what exists; with zero, the prompt says no commands were recorded and still sends the question. Tested in Tasks 3 and 4.
5. **Ctrl-C'd or empty-output commands** (exit 130, nothing printed) still appear with their exit code and empty output. Tested in Task 3.
